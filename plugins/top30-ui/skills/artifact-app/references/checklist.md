# Before you say it's ready

- [ ] `appkit.py lint` shows 0 errors; each remaining warning is fixed or explained.
- [ ] `appkit.py plan` tier matches what the page asks for, and nothing more.
- [ ] `appkit.py budget` for the real refresh schedule is "light" or "moderate".
- [ ] Opens at 360px wide and at full screen without sideways scroll.
- [ ] Light and dark both readable.
- [ ] Works with every permission denied: no crash, a clear message, the core view still there.
- [ ] Works with storage blocked: shows sample or empty state, says changes won't be kept.
- [ ] Offline: says so; online again: recovers without a reload.
- [ ] Notifications: one per event, only after the user turned them on.
- [ ] Every number from a connector shows its source and fetch time.
- [ ] No secrets, no real customer data in sample data.
- [ ] The user knows an edit to an installed app asks for permissions again.
- [ ] Someone has installed it (Share → Install as app) and opened it once. If not, say so.
