How this page moves

No library. One canvas and a function of scroll.

  • Everything you saw is drawn by render(progress, time), so DOM inspectors find a single empty canvas.
  • The scatter is seeded (seed 20261104): the same "random" layout on every visit.
  • Phase ends sit on these cards' data-phase markers, so timing follows the copy at any screen size.
  • A frame loop runs only during the hero drift and the refine stream; elsewhere scroll alone redraws.
  • Canvas resolution follows your screen up to 2x. With reduced motion on you get one still of the finished load.
