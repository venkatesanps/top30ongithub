# Motion stack

Eighteen repos cover five steps: **copy → style → move → sound → ship**. Most films need three
or four of them, not eighteen. This skill picks them, checks the machine, and hands off to the
kit's scripts for the parts the repos leave to you.

## 1. Name the job, then check

```bash
S="python3 ${CLAUDE_PLUGIN_ROOT}/skills/motion-stack/scripts/stack_check.py"   # or this folder's scripts/
$S jobs                  # copy, ui-motion, explainer, math, launch-film, polish, styles, art, 3d,
                         # web-vfx, composite, beat, captions, sound, ship
$S plan launch-film      # first choice, alternatives, what's installed, what's missing, install lines
$S tools                 # node 22+, bun, uv, python 3.11+, ffmpeg 6+ (libass, loudnorm, x264),
                         # Chrome/Chromium, Blender 5.2+, LaTeX, Manim, WhisperX, librosa
```

It is read-only. Show the user the plan and **ask before installing anything**; install with
the catalog's own command (`./install.sh <n>` in the kit repo, or the line `plan` prints).

## 2. Which repo for which step

| Step | Use | When |
|---|---|---|
| Copy | **84** reanimate | Rebuild something you saw; it films original and copy the same way and iterates until they match. For "why can't I reproduce this?", start with `motion-forensics` (top30-ui). |
| Principles | **85** motion-design | Timing, easing, choreography before any code. `motion-budget` (top30-ui) checks the numbers. |
| Style | **86** mg-styles-15 | 15 proven style prompts with source; change only the Creative seed. |
| Paint | **87** huashu-art-motion, **88** anidoodle | Art styles that move (36 painting styles and 9 explainer grammars; 32 drawing styles with scores). |
| Film | **89** cinetic, **100** Remotion skills | Launch and update films in Remotion (or HyperFrames, item 29). |
| Polish | **90** motionmaxxing | Measured rules and gates that fail "slide deck that moves". |
| Math | **91** Manim | Formulas and graphs that transform. |
| 3D | **92** Blender skills | Model, rig, animate, render (needs Blender 5.2+). |
| Web VFX | **93** three.quarks, **94** react-postprocessing, **95** Tweakpane | Particles, bloom/DoF/grain, live sliders. |
| Composite | **96** EffectCraft | After Effects-style layers and keyframes, with a CLI and MCP server. |
| Beat | **98** librosa → `beat-cues` | Beats, bars and sections as frame numbers. |
| Captions | **99** WhisperX → `word-captions` | Word-timed SRT/VTT/ASS karaoke/Remotion captions. |
| Sound | **97** Openverse → `free-sound` | Music and effects your use allows, with the credits file. |
| Ship | **101** FFmpeg → `ship-video` | Platform presets, loudness, captions, and a check that the file passes. |

## 3. A film, end to end

1. Brief in one line: audience, length, format (9:16 or 16:9), the one idea.
2. Style: one source from step 2, not a blend of three.
3. Sound first if it's cut to music: `free-sound` for the track, then `beat-cues analyze` so
   scenes and hits land on beats and downbeats.
4. Build the picture with the chosen repo. Every frame should be reachable by time
   (`renderAt(t)`, Remotion's `useCurrentFrame()`, a Manim scene), so renders are repeatable.
5. Voiceover? `whisperx` then `word-captions build --preset social --out captions.ass`.
6. `ship-video run --preset reels --subs captions.ass --audio track.mp3`; it ends with `check`.
7. Look at a contact sheet before calling it done (`ffmpeg -i out.mp4 -vf fps=1,scale=320:-1,tile=4x3 sheet.png`).

## Rules that apply at work

- **Remotion** (and anything rendering with it: cinetic, video-shotcraft, OpenMontage's
  Remotion pipelines) is free for individuals and companies of up to 3 people; larger
  for-profit companies need a company licence. HyperFrames, Manim and canvas/GSAP pages don't.
- **Copying** (reanimate, motion-forensics): fonts, images, logos and code from another site
  belong to its owner. Copy behaviour to learn or to rebuild your own product; don't ship
  someone else's brand.
- **Sound**: every Openverse file has its own licence; `free-sound` refuses what your use
  doesn't allow and writes `CREDITS.md`. Music generated by cinetic or motionmaxxing comes from
  their own sources; keep their licence records with the project.
- **Hosted services**: LottieFiles' Creator MCP and ElevenLabs (motionmaxxing's optional voice)
  send your content out. WhisperX, librosa, Manim, Blender and FFmpeg run locally.
