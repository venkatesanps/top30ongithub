# weigh

Judge options against criteria that come from the goal, not from habit.

1. **Criteria from frame:** 3-6 things that make an option good for this goal. Include cost to
   change later, risk, and effort if they matter.
2. **Weights:** `(critical)`, `(high)`, `(medium)`, `(low)`. Critical means pass/fail: an option
   that fails a critical criterion is out, however well it scores elsewhere.
3. **Score with evidence,** not adjectives. "Option B: 2 services to change [verified: grep]"
   beats "B is simpler".
4. **Look for the dominated option** (worse on everything) and drop it out loud.
5. **Sensitivity:** would a reasonable change in one weight flip the winner? If yes, that
   weight is the real decision; name it.

Ledger: `criteria (weight)`, `scores`, `critical fails`, `carry` (leader and runner-up, and the
weight the result hinges on).
