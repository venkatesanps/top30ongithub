# integrate

Several modes produce several partial answers. The reply needs one.

1. **Through-line:** one sentence that the rest of the answer supports. If you can't write it,
   the thinking isn't done.
2. **Order by what the user needs first,** usually the decision or fix, then why, then risks,
   then next steps.
3. **Keep the tension that matters:** if two criteria pull in different directions, show the
   tradeoff instead of smoothing it away.
4. **Carry the tags through:** unverified claims stay marked in the final answer, next to the
   sentence that uses them.
5. **Cut:** anything that doesn't serve the through-line goes, including interesting ledger
   detail.

Ledger: `through-line`, `tension kept`, `uncertainty shown`, `carry`.
