Claude Plugins Field Guide

The 30 plugins from the "top 30 on GitHub (by job)" post, each traced to its real repository. A daily job re-checks every repo, re-tests installs and refreshes this page. Pick the row that matches your week and add one.

    Token figures come from claude plugin details: the tokens a plugin adds to every Claude Code session before you invoke anything. Bars use a log scale.

    "Install test" means the install commands ran on a fresh Linux machine in GitHub Actions and the item's check command passed. A few items use a non-interactive variant there (BMAD, REA, OpenMontage); see ci in catalog.json.

    Stars and update dates come from the GitHub API at the last check. The star counts in the original post don't match these in several cases.

    Source, history and the daily job: github.com/venkatesanps/top30ongithub.
