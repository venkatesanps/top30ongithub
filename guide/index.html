Claude Plugins Field Guide

The 30 plugins from the "top 30 on GitHub (by job)" post, plus a data & ops toolkit for Snowflake, dbt, AWS, Oracle, team metrics and production monitoring, the "20 GitHub projects to open first", and Anthropic's own repos for building agents. Every entry is traced to its real repository; a daily job re-checks them, re-tests installs and refreshes this page.

Trying these at work? Read Before you try this at work and the role playbooks first.

    Token figures come from claude plugin details: the tokens a plugin adds to every Claude Code session before you invoke anything. They are estimates and shift between CLI versions; these were measured with . Bars use a log scale.

    "Install test" means the install commands ran on a fresh Linux machine in GitHub Actions and the item's check command passed. A few items use a non-interactive variant there (BMAD, REA, OpenMontage); see ci in catalog.json.

    Stars and update dates come from the GitHub API at the last check. The star counts in the original post don't match these in several cases.
